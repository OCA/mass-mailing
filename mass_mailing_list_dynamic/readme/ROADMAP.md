Odoo also has native *Dynamic Lists*. They don't replace this module:

- A native Dynamic List is a saved filter, applied when the mailing is sent.
  Recipients are not stored in a mailing list.
- Unsubscribing from a mailing sent to a native Dynamic List blocklists the
  email for all mass mailings. With this module, recipients are contacts of a
  real mailing list, so they can leave that list only and keep the others.
- Native Dynamic Lists can't be combined with mailing lists in the same mailing.
